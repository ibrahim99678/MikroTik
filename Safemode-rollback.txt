MikroTik RouterOS-এ রিমোটলি বা প্রোডাকশনে জটিল ফায়ারওয়াল, রাউটিং ও আইপি পরিবর্তনের সময় অসাবধানতাবশত ডিসকানেক্ট বা লকআউট এড়াতে সবচেয়ে নির্ভরযোগ্য কৌশল হলো সেফ মোড (Safe Mode) এবং অটো-রোলব্যাক মেকানিজম ব্যবহার করা।

১. সেফ মোড (Safe Mode) কীভাবে কাজ করে?
সেফ মোড চালুর পর আপনার প্রতিটি কনফিগারেশন চেঞ্জ একটি অস্থায়ী বাফার ট্র্যাকে সংরক্ষিত হয়। যদি কোনো ভুলের কারণে (যেমন: ভুল ফায়ারওয়াল রুল, ইন্টারফেস ড্রপ বা আইপি মিসম্যাচ) রাউটারের সাথে আপনার Winbox বা SSH সংযোগ বিচ্ছিন্ন হয়ে যায়, RouterOS তাৎক্ষণিকভাবে আপনার করা সমস্ত পরিবর্তন স্বয়ংক্রিয়ভাবে রোলব্যাক (বাতিল) করে আগের অবস্থায় ফিরিয়ে নিয়ে যায়।

CLI বা টার্মিনালে চালু করার নিয়ম:

কীবোর্ডে চাপুন: Ctrl + X

টার্মিনাল প্রম্পট পরিবর্তিত হয়ে [admin@MikroTik] <SAFE> / > দেখাবে।

Winbox-এ চালু করার নিয়ম:

উপরে বাঁ দিকের মেনুবারে থাকা Safe Mode বাটনে ক্লিক করুন (বাটনটি প্রেসড হয়ে থাকবে)।

পরিবর্তন স্থায়ী করা (Commit):

কনফিগারেশন সফল হলে এবং সংযোগ ঠিক থাকলে পুনরায় Ctrl + X চাপুন (বা Winbox-এর Safe Mode বাটনে আবার ক্লিক করুন)। এতে পরিবর্তনগুলো স্থায়ীভাবে সেভ হবে।

ম্যানুয়ালি পূর্বাবস্থায় ফেরা (Abort/Cancel):

কোনো সমস্যা বুঝতে পারলে Ctrl + D চাপুন অথবা টার্মিনাল/Winbox সরাসরি ক্লোজ করে দিন; পরিবর্তনগুলো সাথে সাথে রোলব্যাক হবে।

২. স্ক্রিপ্ট রান করার সময় অটো-রোলব্যাক মেকানিজম
বড় স্ক্রিপ্ট বা কনফিগারেশন ইমপোর্ট করার সময় সংযোগ বিচ্ছিন্ন হয়ে গেলে সেফ মোড অনেক সময় স্ক্রিপ্ট চলাকালীন কাজ নাও করতে পারে। সেজন্য প্রোডাকশনে স্ক্রিপ্ট চালুর আগে একটি টাইমার-ভিত্তিক অটো-রিবুট ও রোলব্যাক সেফটি-নেট তৈরি করা সবচেয়ে নিরাপদ।

টেকনিক: Scheduled Rollback Safety-Net
যেকোনো রিস্কি ফায়ারওয়াল বা রাউটিং কমান্ড দেওয়ার আগে বর্তমান কনফিগারেশন ব্যাকআপ রেখে ৫ মিনিটের একটি কাউন্টার শিডিউলার বসিয়ে দিন:

##Code snippet##

# ১. সেফ পয়েন্ট ব্যাকআপ নেওয়া
/system backup save name=pre_change_backup.backup

# ২. একটি ইমার্জেন্সি রিস্টোর শিডিউলার চালু করা (৫ মিনিট পর স্বয়ংক্রিয়ভাবে রিস্টোর হবে)
/system scheduler
add name=emergency_rollback on-event="/system backup load name=pre_change_backup.backup password=\"\"" interval=5m

# ৩. এবার আপনার রিস্কি ফায়ারওয়াল বা নেটওয়ার্ক কনফিগারেশন রান করুন...
# (যদি কানেকশন কেটে যায়, ৫ মিনিট পর রাউটার নিজে রিস্টোর করে রিবুট নেবে)

# ৪. সব ঠিকঠাক থাকলে এবং কানেকশন সচল থাকলে শিডিউলারটি মুছে ফেলুন
/system scheduler remove [find name=emergency_rollback]

৩. রিমোট লকআউট প্রতিরোধের অতিরিক্ত ৩টি প্রো-টিপস
ম্যাক-টেলনেট / ম্যাক-উইনবক্স সক্রিয় রাখা: আইপি সাবনেট বা রাউটিং টেবিল নষ্ট হলেও একই লেয়ার-২ সুইচ/ল্যানে থাকা অবস্থায় MAC Address দিয়ে প্রবেশ করা যায়। তাই ইন্টারফেস লিস্টে LAN ইন্টারফেসে MAC Server সবসময় অনুমোদিত রাখুন:

##Code snippet##

/tool mac-server set allowed-interface-list=LAN
/tool mac-server mac-winbox set allowed-interface-list=LAN

Dedicated Out-of-Band (OOB) ম্যানেজমেন্ট পোর্ট: বড় ডিভাইসে (যেমন CCR বা RB সিরিজের ৪+ পোর্ট রাউটার) একটি নির্দিষ্ট ইথারনেট পোর্ট (যেমন ether1 বা ether8) ব্রিজ থেকে আলাদা রেখে স্ট্যাটিক ম্যানেজমেন্ট আইপি দিয়ে রাখুন।

ফায়ারওয়াল রুল ড্রপ করার আগে নিজের আইপি হোয়াইটলিস্ট: যে আইপি থেকে আপনি লগইন আছেন, ড্রপ রুল অ্যাড করার আগে সেটিকে একটি সেফ অ্যাড্রেস লিস্টে রেখে ফায়ারওয়ালে একসেপ্ট দিয়ে নেওয়া বাধ্যতামূলক।
